# Chord 服务器部署说明（129.226.159.168 新加坡服务器）

> 部署包内容：Linux amd64 后端二进制 + Flutter Web 静态产物 + 一键安装脚本。
> 服务器前置条件（已满足）：MySQL 8（root，127.0.0.1:3306）、Redis（127.0.0.1:6379，无密码）。

## 一、上传与安装

1. 把整个部署包目录上传到服务器任意目录，例如 `/root/chord-deploy/`：

   ```bash
   # 在你本地执行（或用 WinSCP / FinalShell 等图形工具拖拽上传）
   scp chord-deploy.tar.gz root@129.226.159.168:/root/
   ssh root@129.226.159.168   # 登录服务器
   cd /root && tar xzf chord-deploy.tar.gz && cd chord-deploy
   ```

2. 一键安装（root 执行，**密码通过环境变量传入，脚本不内嵌密码**）：

   ```bash
   sudo MYSQL_PASS='<你的数据库root密码>' bash install.sh
   ```

   也可以不手动上传，直接在服务器上从 GitHub Release 拉取安装（新加坡服务器访问 GitHub 很快）：

   ```bash
   curl -fLO https://github.com/zhumin2/discord-like/releases/latest/download/chord-deploy.tar.gz
   tar xzf chord-deploy.tar.gz && cd package
   sudo MYSQL_PASS='<你的数据库root密码>' bash install.sh
   ```

3. **云控制台安全组**（脚本管不到的）：在腾讯云控制台给该实例的安全组放行
   TCP `3000`（Web）与 `8081`（API）。

## 三、日常运维

```bash
systemctl status  chord-server chord-web     # 状态
systemctl restart chord-server               # 重启 API（改 .env 后需要）
systemctl restart chord-web                  # 重启 Web
journalctl -u chord-server -f                # API 日志
journalctl -u chord-web -f                   # Web 日志
```

| 项目 | 位置 |
|---|---|
| 安装目录 | `/opt/chord`（`server/` = API，`web/htdocs/` = 页面） |
| 应用配置 | `/opt/chord/server/.env`（权限 600） |
| JWT 密钥 | `/opt/chord/server/.data/jwt_secret`（首次启动自动生成，**勿外泄勿删除**，删了所有人要重新登录） |
| 数据库 | `chord` 库，表由 GORM 首次启动自动迁移 |

## 四、升级新版本（推荐：GitHub Release 一键更新）

新版发布到 `zhumin2/discord-like` 的 Release 后，服务器上一条命令完成更新：

```bash
# 只更新 Web 前端（最常用，不需要数据库密码）
sudo bash /opt/chord/update.sh web

# 全量重装（后端+前端+配置，需要数据库密码）
sudo MYSQL_PASS='<你的数据库root密码>' bash /opt/chord/update.sh full
```

`update.sh` 会从 `https://github.com/zhumin2/discord-like/releases/latest/download/` 拉取
`chord-web-update.tar.gz` 或 `chord-deploy.tar.gz` 并自动应用、重启服务。

> 提示：更新后浏览器若显示旧版，强制刷新（Ctrl+F5）即可——Flutter Web 有 PWA/Service Worker 缓存。

### 手动升级（备用）

1. 本地重新打包（新的 `chord-server`、`serveweb`、`web/`）上传；
2. 替换文件后重启即可，数据不受影响：

   ```bash
   install -m 0755 chord-server /opt/chord/server/chord-server
   install -m 0755 serveweb     /opt/chord/web/serveweb
   rm -rf /opt/chord/web/htdocs && cp -r web /opt/chord/web/htdocs
   chown -R chord:chord /opt/chord
   systemctl restart chord-server chord-web
   ```

## 五、部署包内容

```
chord-deploy/
├── install.sh        # 一键安装（幂等，可重复执行；密码用 MYSQL_PASS 环境变量传入）
├── update.sh         # 一键更新（从 GitHub Release 拉最新包；web/full 两种模式）
├── chord-server      # Go 后端（静态链接，Linux x86-64）
├── serveweb          # Flutter Web 静态托管（SPA 回退 + wasm MIME）
├── redisprobe        # Redis/presence 状态探针（可选工具）
└── web/              # Flutter Web 构建产物（index.html、main.dart.js、canvaskit/ 等）
```

## 六、已知注意点（来自项目踩坑记录）

- Redis 只是事件扇出/presence 加速，**连不上会自动降级**为进程内模式，不影响启动。
- `SEED_DEMO=true` 仅在**空库**时写入演示数据；已有数据不会被覆盖。
- MySQL 密码含特殊字符时注意 `.env` 的 `DB_DSN` 转义（含 `$`、`@`、`:` 等字符时需按 Go DSN 规则转义）。
- **`UPLOAD_DIR`（v1.1 上传目录）**：install.sh 自动写入 `/opt/chord/data/uploads` 并建目录。
  **备份必须包含它**：`mysqldump chord` + `tar czf uploads.tar.gz /opt/chord/data/uploads` + `server/.data/jwt_secret`。
- 升级后页面仍是旧版：多半是浏览器缓存，`Ctrl + F5` 强制刷新（v1.1 起服务端改为资源 1 小时缓存 + 入口 no-cache）。
- 若后续上 HTTPS/域名：在 `CLIENT_ORIGIN` 加上新来源，并把 Web/API 换成反代（WS 需 wss），
  模板见仓库 `deploy/caddy/Caddyfile`。
