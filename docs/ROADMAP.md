# Chord 开发路线图（Roadmap）

> 文档版本：v1.0 ｜ 日期：2026-11-15 ｜ 节奏：单人 + AI 协作开发
> 上游文档：[PRD](./PRD.md) ｜ 交接背景：[AGENTS.md](../AGENTS.md)
>
> 优先级定义：**P0**=不做会出事故/无法增长 ｜ **P1**=核心竞争力 ｜ **P2**=锦上添花
> 工作量估算按「AI 协作单人」口径（人·日），含自测与文档。

## v1.1 — 安全与体验（目标：3 周内发布）

> 主题：用得放心、加载得快。上线前必须清零的两颗雷：明文 HTTP、Web 首屏慢。

### A. 基础设施（P0，共约 3 人·日）

| # | 工作项 | 内容 | 验收标准 | 估算 |
|---|---|---|---|---|
| A1 | **TLS 反向代理** | 服务器装 Nginx/Caddy，反代 3000（Web）与 8081（API+WS，wss）；域名解析 + 免费证书（Let's Encrypt 自动续期）；`.env` 的 `CLIENT_ORIGIN` 增加新来源 | `https://<域名>` 全功能可用；WS 走 wss；HTTP 301 跳转 | 1 |
| A2 | **静态资源压缩** | serveweb 加 gzip/brotli（Go `compress/gzip` 或 Caddy 自带）；Web 构建产物 hash 文件缓存头 | 首屏传输量 10MB→约 2.5MB；二次访问命中缓存 <1s | 0.5 |
| A3 | **基础限流** | 注册/登录按 IP 频控（如 10 次/分）；发消息按用户频控（如 20 条/10s）；返回 429 | 超频请求被拒且前端提示友好 | 1 |
| A4 | **数据库备份** | cron 每日 mysqldump + 异地（下载到本地/对象存储）保留 7 天 | 恢复演练一次成功 | 0.5 |

### B. 图片/文件上传（P0，约 3 人·日）

| # | 工作项 | 内容 | 验收标准 | 估算 |
|---|---|---|---|---|
| B1 | 上传 API | `POST /api/upload`（multipart）：≤10MB，图片 jpg/png/webp/gif + 任意文件白名单；存 `{data_dir}/uploads/{yyyyMM}/{uuid}.{ext}`；消息 content 支持 markdown 图片语法 | 频道/DM 发图即时显示；文件可下载 | 1 |
| B2 | 静态服务 | serveweb 或 API 侧提供 `/uploads/` 读取（Content-Type 正确、防路径穿越、Cache-Control 长缓存） | URL 直开图片成功；穿越攻击被拒 | 0.5 |
| B3 | 客户端 UI | 粘贴/选择图片→压缩→上传→插入消息；图片点击看大图；多端（Web/Win/Android）适配 | 三端可发可看 | 1 |
| B4 | 清理策略 | 孤儿上传（未被消息引用）定期清理 | 脚本跑通 | 0.5 |

### C. 测试基建（P1，约 2 人·日，贯穿 v1.1）

| # | 工作项 | 内容 | 验收标准 | 估算 |
|---|---|---|---|---|
| C1 | Go 测试 | `internal/handlers` httptest 覆盖 auth/guild/message/DM 主链路；CI 脚本 `go test ./...` | 核心接口覆盖率 >70%；本地一键跑 | 1.5 |
| C2 | 发布检查单 | 发布前 checklist：构建三端→冒烟（redisprobe/health/双账号互发）→Release 上传 | 每次发布照单执行 | 0.5 |

**v1.1 发布内容**：HTTPS 域名上线、可发图片、首屏 <10s、有测试兜底。
**发布动作**：tag v1.1.0 → Release 上传三端包 + 服务器包 → 服务器 `update.sh full`。

## v1.2 — 社群成长（目标：v1.1 后 4-6 周）

> 主题：留得住人。权限、搜索、通知是社群活跃的三件套。

### A. 角色权限体系（P1，约 4 人·日）

| # | 工作项 | 内容 | 验收标准 | 估算 |
|---|---|---|---|---|
| A1 | 数据模型 | `role` 表 + 成员多角色；权限点：管理频道/管理角色/踢人/删消息/发消息/上传…… | owner 之外可授予管理员 | 1 |
| A2 | 服务端鉴权 | 中间件按权限点校验（替代现有 owner 硬判断，集中在 handlers） | 无权限操作返回 403 | 1.5 |
| A3 | 客户端 UI | 服务器设置页：角色管理、成员角色分配；无权限按钮隐藏/置灰 | 管理员可建角色并生效 | 1.5 |

### B. 消息搜索（P1，约 3 人·日）

| # | 工作项 | 内容 | 验收标准 | 估算 |
|---|---|---|---|---|
| B1 | MySQL 全文索引 | `ngram` 分词 FULLTEXT（utf8mb4 中文可用），按频道+关键词查询，走现有游标分页风格 | 搜"部署"能命中历史消息 <300ms | 1.5 |
| B2 | 搜索 UI | 频道内搜索入口 + 结果列表 + 点击跳转定位 | 三端可用 | 1.5 |

### C. 通知（P1，约 3 人·日）

| # | 工作项 | 内容 | 验收标准 | 估算 |
|---|---|---|---|---|
| C1 | 桌面/Web 通知 | Web Notification API + Windows 原生 toast（走现有原生通道，不加插件）；@提及/DM 触发 | 关窗口收 DM 有提醒（Web 保留后台 SW） | 2 |
| C2 | 未读红点强化 | 任务栏/托盘未读数（Windows） | 托盘图标角标显示未读 | 1 |

### D. 好友系统（P2，约 3 人·日）

好友申请/列表/删除；好友在线状态聚合；DM 入口收敛到好友优先。

**v1.2 发布**：角色权限 + 搜索 + 通知 +（可选）好友；Android 正式 keystore 签名（0.5 日）。

## v1.3 — 实时语音（目标：v1.2 后 6-8 周）

> 主题：核心差异化。AGENTS.md 已预留 ws/ 与频道模型扩展点。

| # | 工作项 | 内容 | 验收标准 | 估算 |
|---|---|---|---|---|
| S1 | 技术验证 spike | WebRTC mesh POC：2-3 人连麦（SFU 留待 v2，mesh 先行）；信令复用现有 WS hub（新事件类型 voice_join/leave/offer/answer/ice） | 两人互听延迟 <400ms | 3 |
| S2 | 频道模型扩展 | 频道类型 `voice`；语音成员列表；服务端房间状态机（成员进退、静音状态广播） | 进出频道全员实时可见 | 2 |
| S3 | 客户端语音 UI | 加入/离开/静音/听筒控制；手机端（Android）回声消除默认开 | 三端进同一语音频道互通 | 4 |
| S4 | 稳定性 | ICE 重连、断网降级提示；服务器带宽评估（mesh 每路 ≈ 上行×(N-1)） | 弱网不炸聊；给出 3 人上限说明 | 2 |

**风险**：新加坡服务器带宽小，mesh 3 人以上即可能吃满上行——上线时明确"语音 3 人内可用"，SFU/TURN 列入 v2。TURN 服务器需要另配（coturn）。

## 执行约定（每个工作项通用的 DoD）

1. 代码合入 main 前本地通过 `go vet` / `go test ./...`（v1.1 C1 后）
2. 涉及 UI 的改动：`scripts/guitest` 走查双视口截图无回归
3. 涉及部署的改动：同步更新 `deploy/部署说明.md` 与 AGENTS.md 踩坑记录
4. 每次发布：三端产物 + 服务器包进 GitHub Release（ASCII 文件名）；线上冒烟（health / 双账号互发 / 语音如适用）
5. 客户端默认服务器地址如变更：重新以 `--dart-define=CHORD_DEFAULT_BASE=` 构建三端

## 依赖与前置

- 域名（TLS 需要）——需你购买/指定；现有裸 IP 可继续用 HTTP 过渡
- Android 正式签名 keystore——生成后妥善备份（丢失无法升级安装）
- TURN 服务器（v1.3 语音弱网穿透）——可用 coturn 同机部署，注意带宽
- CDN（可选但强推）——腾讯云 CDN 挂 Web 静态资源，首屏指标达标的最稳路径
